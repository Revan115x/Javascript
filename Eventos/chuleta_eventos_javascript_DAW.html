1. La estructura que debes reconocer

Un evento es algo que hace el usuario: pulsar un botón, escribir, mover el ratón, cambiar una opción, etc.

// HTML
<button id="miBoton">Pulsa</button>

// JavaScript
let boton = document.getElementById("miBoton");

boton.addEventListener("click", function() {
    alert("Has pulsado el botón");
});

La lógica:

  1. Selecciono el elemento con getElementById().
  2. Le añado un evento con addEventListener().
  3. Dentro de la función escribo lo que debe ocurrir.
Importante: si el JavaScript está en un archivo aparte, carga el script con defer o coloca el script al final del body, para que el HTML exista cuando lo busques.

Dos formas de asociar eventos

// Forma recomendada: addEventListener
boton.addEventListener("click", function() {
    alert("Hola");
});

// Forma directa: propiedad del evento
boton.onclick = function() {
    alert("Hola");
};

En los ejercicios, usa preferentemente addEventListener. Permite asociar más de una función al mismo evento.

2. click: hacer algo al pulsar un botón

Ejemplo A. Mostrar un mensaje

let boton = document.getElementById("saludar");

boton.addEventListener("click", function() {
    alert("¡Hola!");
});

Ejemplo B. Cambiar el contenido de una página

let boton = document.getElementById("cambiar");
let texto = document.getElementById("mensaje");

boton.addEventListener("click", function() {
    texto.innerHTML = "Texto cambiado";
});

Este es el texto original.

Ejemplo C. Mostrar u ocultar un elemento

let boton = document.getElementById("ocultar");
let texto = document.getElementById("secreto");

boton.addEventListener("click", function() {
    if (texto.style.display == "none") {
        texto.style.display = "block";
    } else {
        texto.style.display = "none";
    }
});

Ahora me puedes ocultar o volver a mostrar.

3. input: reaccionar mientras escribes

Se ejecuta cada vez que cambia el contenido de un campo de texto. Es muy útil para validar contraseñas o mostrar lo que se está escribiendo.

Ejemplo A. Mostrar en pantalla lo escrito

let cajaTexto = document.getElementById("nombre");
let resultado = document.getElementById("resultadoNombre");

cajaTexto.addEventListener("input", function() {
    resultado.innerHTML = cajaTexto.value;
});

Estás escribiendo:

Ejemplo B. Comprobar si un campo está vacío

let campo = document.getElementById("usuario");
let aviso = document.getElementById("avisoUsuario");

campo.addEventListener("input", function() {
    if (campo.value.trim() == "") {
        aviso.innerHTML = "El campo está vacío";
    } else {
        aviso.innerHTML = "Campo correcto";
    }
});

Escribe para comprobarlo.

Ojo con value y innerHTML: value obtiene lo que hay escrito en un input. innerHTML cambia o lee el contenido de un elemento como un p o un span.

Ejemplo C. Validar una contraseña con clases

let password = document.getElementById("password");
let indicador = document.getElementById("indicador");

password.addEventListener("input", function() {
    if (password.value.trim().length >= 8) {
        indicador.innerHTML = "Contraseña válida";
        indicador.className = "valido";
    } else {
        indicador.innerHTML = "Mínimo 8 caracteres";
        indicador.className = "invalido";
    }
});

Mínimo 8 caracteres

trim() quita espacios del principio y del final. length indica la cantidad de caracteres. className cambia la clase CSS del elemento.

4. Eventos de teclado

Se usan cuando el usuario pulsa o suelta una tecla. Para saber qué tecla ha pulsado, se utiliza event.key.

Ejemplo A. Detectar una tecla

document.addEventListener("keydown", function(event) {
    if (event.key == "Enter") {
        alert("Has pulsado Enter");
    }
});

Prueba a pulsar Enter dentro del campo.

Ejemplo B. Contar caracteres al escribir

let texto = document.getElementById("textoContar");
let contador = document.getElementById("contador");

texto.addEventListener("input", function() {
    contador.innerHTML = texto.value.length;
});

Caracteres: 0

Teclas que pueden pedirte

  • event.key == "Enter": tecla Intro.
  • event.key == "Backspace": retroceso / borrar hacia atrás.
  • event.key == " ": barra espaciadora.
  • event.key == "ArrowLeft": flecha izquierda.
  • event.key == "a": letra a (la comparación distingue mayúsculas/minúsculas).
No confundas: keydown ocurre al pulsar la tecla; keyup al soltarla; input cuando cambia el valor del campo. Para detectar qué se ha escrito en un input, normalmente es más sencillo usar input.

6. change, focus, blur y submit

Ejemplo A. change: detectar un cambio en un select

let lista = document.getElementById("colores");
let resultadoColor = document.getElementById("resultadoColor");

lista.addEventListener("change", function() {
    resultadoColor.innerHTML = "Has elegido: " + lista.value;
});

Todavía no has elegido.

Ejemplo B. focus y blur

let campoFocus = document.getElementById("campoFocus");
let ayuda = document.getElementById("ayuda");

campoFocus.addEventListener("focus", function() {
    ayuda.innerHTML = "Escribe tu correo";
});

campoFocus.addEventListener("blur", function() {
    ayuda.innerHTML = "Has salido del campo";
});

El mensaje cambiará al entrar o salir del campo.

Ejemplo C. submit: comprobar un formulario

let formulario = document.getElementById("formulario");
let nombreForm = document.getElementById("nombreForm");

formulario.addEventListener("submit", function(event) {
    if (nombreForm.value.trim() == "") {
        event.preventDefault(); // Evita que se envíe el formulario
        alert("Debes escribir tu nombre");
    }
});

Prueba a enviar vacío y después escribe un nombre. Este ejemplo evita el envío real para que puedas probarlo en esta página.

Recuerda: event.preventDefault() cancela el comportamiento predeterminado. En un formulario evita el envío; en un enlace puede evitar la navegación.

7. Patrones de lógica que se repiten en los exámenes

A. Si el usuario pulsa un botón, comprobar una condición

boton.addEventListener("click", function() {
    if (condicion) {
        // Lo que ocurre si se cumple
    } else {
        // Lo que ocurre si no se cumple
    }
});

B. Si el usuario escribe, leer el valor del input

campo.addEventListener("input", function() {
    let texto = campo.value;

    if (texto == "") {
        resultado.innerHTML = "No has escrito nada";
    } else {
        resultado.innerHTML = texto;
    }
});

C. Cambiar estilos desde JavaScript

elemento.style.color = "red";
elemento.style.backgroundColor = "yellow";
elemento.style.display = "none";  // Ocultar
elemento.style.display = "block"; // Mostrar

D. Trabajar con clases CSS

elemento.className = "valido";
elemento.className = "invalido";

E. Confirmar antes de realizar una acción

boton.addEventListener("click", function() {
    let respuesta = confirm("¿Seguro que quieres continuar?");

    if (respuesta == true) {
        alert("Has aceptado");
    } else {
        alert("Has cancelado");
    }
});

F. Recoger el valor de varios controles

// Input de texto
let nombre = document.getElementById("nombre").value;

// Select
let opcion = document.getElementById("colores").value;

// Radio: buscar el radio marcado
let elegido = document.querySelector('input[name="alineacion"]:checked');

if (elegido != null) {
    let valor = elegido.value;
}
Atención: en los radio buttons, querySelector(...:checked) obtiene el que está seleccionado. Comprueba que no sea null antes de leer .value.

9. Errores típicos que debes revisar

  • Escribir getElementById("nombre") sin que exista un elemento con ese id.
  • Olvidar que los textos de un input se leen con .value, no con .innerHTML.
  • Escribir if (campo.value = ""). Para comparar usa == (o === si ya lo estáis usando).
  • Olvidar los paréntesis y las llaves de la función del evento.
  • Usar change cuando necesitas reaccionar a cada tecla: normalmente corresponde input.
  • Intentar leer .value de un radio sin comprobar si hay alguno seleccionado.
  • Olvidar event.preventDefault() cuando el ejercicio pide validar un formulario antes de enviarlo.
  • Olvidar defer si el script se carga en el head.

10. Cómo plantear un ejercicio nuevo en el examen

  1. Identifica qué acción hace el usuario: clic, escribir, tecla, ratón, cambio o envío.
  2. Selecciona los elementos: botones, inputs, párrafos, imágenes, select, formulario.
  3. Asocia el evento: addEventListener("evento", function(event) { ... }).
  4. Obtén los datos: normalmente input.value o event.key.
  5. Decide qué debe pasar: if / else, cambiar texto, estilo, clase o mostrar un aviso.
  6. Prueba casos distintos: vacío, correcto, incorrecto, tecla especial, volver a pulsar, etc.

Idea clave: casi todos los ejercicios de eventos siguen esta cadena: seleccionar elemento → escuchar evento → obtener dato → comprobar condición → modificar la página.
